## India state boundaries

`india-states.geojson` contains 36 state and Union Territory geometries from the 2024 Local Government Directory (LGD) snapshot, distributed through bharatlas / geoBoundaries. The data is licensed CC0-1.0 / CC-BY-4.0. The repository copy was simplified to 0.008 degrees for web display; state names and properties are retained.

Sources:

- [bharatlas States (2024)](https://bharatlas.com/view/gb_adm1)
- [Local Government Directory](https://lgdirectory.gov.in/)
- [geoBoundaries](https://www.geoboundaries.org/)

The map colors states only from company shipment destination-state counts returned by the authenticated customer summary API. It does not show hub pins or imply exact hub locations.
